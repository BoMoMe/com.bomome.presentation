# Changelog

## 0.2.0 - 2026-10-26
- Add independent reward-flight handles and batches with explicit terminal outcomes.
- Add optional Coffee UI Particle/LeanPool profiles, presenter, targets and UnityEvent trigger.

- Keep Coffee simulation callbacks separate from user feedback and reward/economy rules.
- Add lifecycle tests and a full authoring/integration guide.
